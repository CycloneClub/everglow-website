## New Content List

### Events

| Name | Chinese Name | Description |
| ---- | --- | ---- |
| Lantern Moon | 灯笼月 | Reworked invasion progression, adjusted enemy spawns and combat pacing, and added weapons, rewards, music, and effects |

### NPCs

| Name | Chinese Name | Description |
| ---- | --- | ---- |
| Lantern Ghost King (Boss) | 灯笼鬼王（BOSS） | Reworked and adjusted abilities, attack pacing, and phase transitions, with new battle music and effects |
| Little Red Paper Figure | 红纸小人 | A Lantern Moon enemy with new and adjusted behavior and paper particle effects |
| Redpaper Giant | 红纸巨人 | A Lantern Moon enemy with updated behavior and paper particle effects |
| Wizard Lantern | 巫师灯笼 | A Lantern Moon enemy with additional abilities, textures, and debris effects |

### Weapons

| Name | Chinese Name | Description |
| ---- | --- | ---- |
| Gilding Revolver | 鎏金左轮枪 | Ranged weapon |
| Golden Lotus Staff | 金莲花法杖 | Summoning weapon |
| Kerosene Lantern Flame Thrower | 火水喷射器 | Ranged weapon; flamethrower |
| Red Oiled Paper Sword | 红油纸剑 | Melee weapon |
| Lantern Yoyo | 灯笼悠悠球 | Yoyo |
| Million Light Staff | 千灯法杖 | Magic weapon |

### Miscellaneous

| Name | Chinese Name | Description |
| ---- | --- | ---- |
| Lantern Ghost King Treasure Bag | 灯笼鬼王宝藏袋 | Boss reward |
| Lantern Ghost King Commemorative Statue | 灯笼鬼王纪念雕像 | Boss memento |
| New Elevator | 新电梯 | Travels between floors and slows to a stop, with a right-click menu for toggling lights and removing the elevator, plus multiple appearances |

### Other Updates

| Content | Description |
| ---- | ---- |
| Layered Backgrounds | Added support for layered backgrounds, with scenery at different distances moving at different rates as the camera moves. Fade transitions help add depth to future scenes |
| Subworld Multiplayer | Advanced state transfer between the main world and subworlds in preparation for future subworld multiplayer content |
| Lantern Moon Audio and Visuals | Added battle music, weapon sounds, paper particles, burning debris, and other effects |
| Weapon Adjustments | Adjusted stats and fixed ammunition consumption, attack speed scaling, and use under reversed gravity for some weapons |
