## 開始遊玩

請先閱讀[安裝指南](/zh-hk/docs/getting-started/installation){target="_self"}，再前往 [Steam 創意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094) 或 [開發版 Releases](https://github.com/CycloneClub/Everglow/releases/tag/dev) 取得流光無際，並按照指南完成安裝。

## 參與貢獻

歡迎提交程式碼、文件、翻譯與設計改進。開始前請閱讀[貢獻指南](https://github.com/CycloneClub/Everglow/blob/1.4.4/CONTRIBUTING.md)，並在各社群空間遵守[行為準則](https://github.com/CycloneClub/Everglow/blob/1.4.4/CODE_OF_CONDUCT.md)。

歡迎[提交問題或建議](https://github.com/CycloneClub/Everglow/issues/new)，也可以透過 Pull Request 參與改進。

想與製作組或其他 tModLoader 玩家交流，可以加入我們的 [Discord 社群](https://discord.gg/pdXvp89Dbp)。
