您可以選擇 [搶先體驗](#搶先體驗版) 或 [開發版](#開發版-github) 進行安裝。

## 搶先體驗版

### 在 Steam 上下載

開啟這個 [連結](https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094)，或直接在 tModLoader 創意工坊搜尋「流光無際」。

### 在沒有 Steam 的情況下下載

1. 前往 [Steam 創意工坊下載器](https://steamworkshopdownloader.io/)。

2. 貼上創意工坊連結 `https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094`。

3. 按照指引進行操作。

## 開發版 (GitHub)

### 從 GitHub Release 下載

前往 [開發版 Release 頁面](https://github.com/CycloneClub/Everglow/releases/tag/dev)，在 Assets（資源）中下載開發版模組檔案，無需自行編譯。

### 從原始碼建置

如果您希望自行編譯開發版，請按照以下步驟操作。

#### 請在開始前準備以下工具

- [**.NET 8.0（或更高版本）SDK**](https://dotnet.microsoft.com/download/dotnet/8.0) - 建置模組檔案
- [**Visual Studio**](https://visualstudio.microsoft.com/) - 開啟與編輯專案
- [**Git**](https://git-scm.com/downloads) - 執行 git 指令

#### 第 1 步

將模組專案下載至 `%userprofile%/Documents/My games/Terraria/tModLoader/ModSources`。

在命令列中使用 `git clone https://github.com/Solaestas/Everglow` 複製儲存庫，或使用 GitHub 頁面上的 Code → Download ZIP 按鈕取得檔案。

#### 第 2 步

若要建置 Everglow，請在專案目錄下開啟命令提示字元。
您可以在 Windows 檔案總管中按住 Shift，再按滑鼠右鍵並選擇「在此處開啟命令視窗」。
然後輸入 `dotnet build`。建置完成的檔案可在新建立的 `build` 目錄中找到。
