## 新內容清單

### 事件

| 名稱 | 描述 |
| ---- | ---- |
| 燈籠月 | 重製入侵流程，調整敵人出現方式與戰鬥節奏，補充武器、獎勵、音樂和特效 |

### NPC

| 名稱 | 英文名稱 | 描述 |
| ---- | -------- | ---- |
| 燈籠鬼王（BOSS） | Lantern Ghost King | 重做與調整技能、攻擊節奏和階段切換，新增戰鬥音樂與特效 |
| 紅紙小人 | Little Red Paper Figure | 燈籠月敵人，新增並調整行為與紙片特效 |
| 紅紙巨人 | Redpaper Giant | 燈籠月敵人，更新行為與紙片特效 |
| 巫師燈籠 | Wizard Lantern | 燈籠月敵人，補充技能、貼圖與碎片效果 |

### 武器

### 雜項

| 名稱 | 描述 |
| ---- | ---- |
| 燈籠鬼王寶藏袋 | BOSS 獎勵 |
| 燈籠鬼王紀念雕像 | BOSS 紀念物 |
| 新電梯 | 在樓層間升降、減速停靠，支援右鍵打開選單、切換燈光和移除電梯，並補充多種外觀 |

### 其他更新

| 內容 | 描述 |
| ---- | ---- |
| 多層次背景 | 新增分層背景支援，讓不同遠近的景物隨鏡頭移動形成視差，並通過淡入淡出銜接，為後續場景增添空間層次 |
| 子世界連線 | 推進主世界與子世界之間的狀態傳遞，為後續子世界連線內容做準備 |
| 燈籠月音畫表現 | 補充戰鬥音樂、武器音效、紙片與燃燒碎片等效果 |
| 武器調整 | 調整数值，修正部分武器的彈藥消耗、攻擊速度適配和反向重力下的使用問題 |
