## 新内容清单

### 事件

| 名称 | 描述 |
| ---- | ---- |
| 灯笼月 | 重制入侵流程，调整敌人出现方式与战斗节奏，补充武器、奖励、音乐和特效 |

### NPC

| 名称 | 英文名称 | 描述 |
| ---- | -------- | ---- |
| 灯笼鬼王（BOSS） | Lantern Ghost King | 重做与调整技能、攻击节奏和阶段切换，新增战斗音乐与特效 |
| 红纸小人 | Little Red Paper Figure | 灯笼月敌人，新增并调整行为与纸片特效 |
| 红纸巨人 | Redpaper Giant | 灯笼月敌人，更新行为与纸片特效 |
| 巫师灯笼 | Wizard Lantern | 灯笼月敌人，补充技能、贴图与碎片效果 |

### 武器

| 金莲花法杖 | Golden Lotus Staff | 召唤武器 |

### 杂项

| 名称 | 描述 |
| ---- | ---- |
| 灯笼鬼王宝藏袋 | BOSS 奖励 |
| 灯笼鬼王纪念雕像 | BOSS 纪念物 |
| 新电梯 | 在楼层间升降、减速停靠，支持右键打开菜单、切换灯光和移除电梯，并补充多种外观 |

### 其他更新

| 内容 | 描述 |
| ---- | ---- |
| 多层次背景 | 新增分层背景支持，让不同远近的景物随镜头移动形成视差，并通过淡入淡出衔接，为后续场景增添空间层次 |
| 子世界联机 | 推进主世界与子世界之间的状态传递，为后续子世界联机内容做准备 |
| 灯笼月音画表现 | 补充战斗音乐、武器音效、纸片与燃烧碎片等效果 |
| 武器调整 | 调整数值，修正部分武器的弹药消耗、攻击速度适配和反向重力下的使用问题 |
