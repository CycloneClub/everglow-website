## 新内容清单

### 地图与探索

| 名称 | 描述 |
| ---- | ---- |
| 暮光遗迹 | 在石鳞木围成的大空洞内加入草地、土层、城堡与城垛，继续丰富天穹镇的探索空间 |
| 生命灯木 | 灯木林中加入大型分叉树木，树干内部留出中空空间，成为林区的新地标 |
| 青缎矿区 | 扩大城镇下方的矿区与隧道，并接入城镇地基生成 |
| 天穹树晶塔遗迹 | 主世界出生点附近新增遗迹入口，右键晶塔播放传送演出，往返天穹树 |
| 石桥与索道 | 完善午夜沼泽一带的石桥，铺设城镇右侧通往源晶塔方向的索道路线；缆车运动继续调整，乘坐交互仍待完善 |
| 区域背景 | 午夜沼泽加入多层视差背景、区域渐变及昼夜音乐选择；天穹镇加入远近背景 |
| 灯木遗迹宝箱 | 房间宝箱接入探索奖励，年末主奖励扩展为七选一，包含琥珀武器、七发猎枪、天穹岩陀螺和三件探索饰品 |
| 房间与存档 | 大理石门接入房间切换与返回逻辑，室内暂用通用木屋；年末启用天穹树保存，实际存档与返回效果仍待验证 |
