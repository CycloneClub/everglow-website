## 新內容清單

### 地圖與探索

| 名稱 | 描述 |
| ---- | ---- |
| 暮光遺跡 | 在石鱗木圍成的大空洞內加入草地、土層、城堡與城垛，繼續豐富天穹鎮的探索空間 |
| 生命燈木 | 燈木林中加入大型分叉樹木，樹幹內部留出中空空間，成為林區的新地標 |
| 青緞礦區 | 擴大城鎮下方的礦區與隧道，並接入城鎮地基生成 |
| 天穹樹晶塔遺跡 | 主世界出生點附近新增遺跡入口，右鍵晶塔播放傳送演出，往返天穹樹 |
| 石橋與索道 | 完善午夜沼澤一帶的石橋，鋪設城鎮右側通往源晶塔方向的索道路線；纜車運動繼續調整，乘坐互動仍待完善 |
| 區域背景 | 午夜沼澤加入多層視差背景、區域漸變及晝夜音樂選擇；天穹鎮加入遠近背景 |
| 燈木遺跡寶箱 | 房間寶箱接入探索獎勵，年末主獎勵擴展為七選一，包含琥珀武器、七發獵槍、天穹岩陀螺和三件探索飾品 |
| 房間與存檔 | 大理石門接入房間切換與返回邏輯，室內暫用通用木屋；年末啟用天穹樹保存，實際存檔與返回效果仍待驗證 |
