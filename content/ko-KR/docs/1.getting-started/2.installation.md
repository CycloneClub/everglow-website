[얼리 액세스 버전](#얼리-액세스-버전) 또는 [개발 버전](#개발-버전-github)을 선택해 설치할 수 있습니다.

## 얼리 액세스 버전

### Steam에서 다운로드

[이 링크](https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094)를 열거나 tModLoader 창작마당에서 "流光无际"를 검색하세요.

### Steam 없이 다운로드

1.  [Steam Workshop Downloader](https://steamworkshopdownloader.io/)로 이동합니다.

2.  창작마당 링크 `https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094`를 붙여 넣습니다.

3.  사이트의 안내에 따라 진행합니다.

## 개발 버전 (GitHub)

### GitHub Releases에서 다운로드

[개발 버전 릴리스 페이지](https://github.com/CycloneClub/Everglow/releases/tag/dev)를 열고 Assets에서 개발 버전 모드 파일을 다운로드하세요. 컴파일할 필요는 없습니다.

### 소스 코드에서 빌드

개발 버전을 직접 컴파일하려면 아래 단계를 따르세요.

#### 사전 준비

- [**.NET 8.0 이상 SDK**](https://dotnet.microsoft.com/download/dotnet/8.0) - 모드 빌드에 사용합니다
- [**Visual Studio**](https://visualstudio.microsoft.com/) - 프로젝트를 열고 편집하는 데 사용합니다
- [**Git**](https://git-scm.com/downloads) - Git 명령을 실행하는 데 사용합니다

#### 1단계

`%userprofile%/Documents/My games/Terraria/tModLoader/ModSources`에 모드를 복제합니다.

명령줄에서 `git clone https://github.com/Solaestas/Everglow`를 실행해 저장소를 복제하거나 Code --> Download zip 버튼으로 파일을 다운로드합니다.

#### 2단계

Everglow를 빌드하려면 프로젝트 디렉터리에서 명령 프롬프트를 엽니다.
Windows에서는 파일 탐색기에서 Shift 키를 누른 채 마우스 오른쪽 버튼을 클릭한 다음 `Open command window here`를 선택하면 빠르게 열 수 있습니다.
그런 다음 `dotnet build` 명령을 실행합니다. 빌드된 파일은 새로 생성된 build 디렉터리에 저장됩니다.
