## 开始游玩

请先阅读[安装指南](/docs/getting-started/installation){target="_self"}，再前往 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094) 或 [开发版 Releases](https://github.com/CycloneClub/Everglow/releases/tag/dev) 获取流光无际，并按指南完成安装。

## 参与贡献

欢迎提交代码、文档、翻译和设计改进。开始前请阅读[贡献指南](https://github.com/CycloneClub/Everglow/blob/1.4.4/CONTRIBUTING.md)，并在各社区空间遵守[行为准则](https://github.com/CycloneClub/Everglow/blob/1.4.4/CODE_OF_CONDUCT.md)。

欢迎[提交问题或建议](https://github.com/CycloneClub/Everglow/issues/new)，也可以通过 Pull Request 参与改进。

想与制作组或其他 tModLoader 玩家交流，可以加入我们的 [Discord 社区](https://discord.gg/pdXvp89Dbp)。
