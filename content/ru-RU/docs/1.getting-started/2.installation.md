Вы можете установить [версию раннего доступа](#версия-раннего-доступа) или [версию для разработчиков](#версия-для-разработчиков-github).

## Версия раннего доступа

### Скачивание через Steam

Перейдите по этой [ссылке](https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094) или найдите «流光无际» непосредственно в мастерской tModLoader.

### Скачивание без Steam

1.  Откройте [Steam Workshop Downloader](https://steamworkshopdownloader.io/).

2.  Вставьте ссылку на мастерскую: `https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094`.

3.  Следуйте инструкциям на сайте.

## Версия для разработчиков (GitHub)

### Скачивание из релизов GitHub

Откройте [страницу версии для разработчиков](https://github.com/CycloneClub/Everglow/releases/tag/dev) и скачайте файлы мода из раздела Assets. Компиляция не требуется.

### Сборка из исходного кода

Если вы хотите самостоятельно скомпилировать версию для разработчиков, выполните следующие действия.

#### Необходимые инструменты

- [**SDK .NET 8.0 (или новее)**](https://dotnet.microsoft.com/download/dotnet/8.0) — для сборки мода
- [**Visual Studio**](https://visualstudio.microsoft.com/) — для открытия и редактирования проекта
- [**Git**](https://git-scm.com/downloads) — для выполнения команд git

#### Шаг 1

Клонируйте мод в `%userprofile%/Documents/My games/Terraria/tModLoader/ModSources`.

Чтобы получить файлы, клонируйте репозиторий командой `git clone https://github.com/Solaestas/Everglow` в командной строке или нажмите Code --> Download zip.

#### Шаг 2

Для сборки Everglow откройте командную строку в каталоге проекта.
В Windows это можно быстро сделать, удерживая Shift в Проводнике, нажав правую кнопку мыши и выбрав `Open command window here` («Открыть окно команд»).
Затем выполните команду `dotnet build`. Результат сборки появится в созданном каталоге build.
