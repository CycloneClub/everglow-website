## 新コンテンツ一覧

### イベント

| 名前 | 中国語名 | 説明 |
| ---- | --- | ---- |
| Lantern Moon | 灯笼月 | 襲撃イベントの進行を刷新し、敵の出現と戦闘のテンポを調整。武器、報酬、音楽、エフェクトを追加 |

### NPC

| 名前 | 中国語名 | 説明 |
| ---- | --- | ---- |
| Lantern Ghost King（ボス） | 灯笼鬼王（BOSS） | 能力、攻撃のテンポ、フェーズ移行を刷新・調整し、新しい戦闘曲とエフェクトを追加 |
| Little Red Paper Figure | 红纸小人 | 行動の追加・調整と紙のパーティクルエフェクトが施されたLantern Moonの敵 |
| Redpaper Giant | 红纸巨人 | 行動を更新し、紙のパーティクルエフェクトを備えたLantern Moonの敵 |
| Wizard Lantern | 巫师灯笼 | 能力、テクスチャ、破片のエフェクトを追加したLantern Moonの敵 |

### その他の更新

| 内容 | 説明 |
| ---- | ---- |
| 多層背景 | カメラの移動に合わせて、距離の異なる景色がそれぞれ異なる速さで動く多層背景に対応。フェードによる切り替えで、今後のシーンに奥行きを加えられる |
| サブワールドのマルチプレイ | 今後のサブワールドでのマルチプレイコンテンツに備え、メインワールドとサブワールド間の状態の引き継ぎを整備 |
| Lantern Moonの音響と視覚効果 | 戦闘曲、武器の効果音、紙のパーティクル、燃える破片、その他のエフェクトを追加 |
| 武器の調整 | 一部の武器の性能を調整し、弾薬消費、攻撃速度の補正、重力反転中の使用に関する問題を修正 |
