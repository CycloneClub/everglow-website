[早期アクセス版](#早期アクセス版)または[開発版](#開発版-github)を選んでインストールできます。

## 早期アクセス版

### Steamからダウンロード

[こちらのリンク](https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094)を開くか、tModLoaderのワークショップで「流光无际」を検索してください。

### Steamを使わずにダウンロード

1.  [Steam Workshop Downloader](https://steamworkshopdownloader.io/)を開きます。

2.  ワークショップのリンク`https://steamcommunity.com/sharedfiles/filedetails/?id=2906178094`を貼り付けます。

3.  サイトの案内に従って進めます。

## 開発版 (GitHub)

### GitHub Releasesからダウンロード

[開発版のリリースページ](https://github.com/CycloneClub/Everglow/releases/tag/dev)を開き、Assetsから開発版のModファイルをダウンロードしてください。コンパイルは不要です。

### ソースコードからビルド

開発版を自分でコンパイルする場合は、以下の手順に従ってください。

#### 必要なもの

- [**.NET 8.0以降のSDK**](https://dotnet.microsoft.com/download/dotnet/8.0) - Modのビルドに使用します
- [**Visual Studio**](https://visualstudio.microsoft.com/) - プロジェクトを開いて編集するために使用します
- [**Git**](https://git-scm.com/downloads) - Gitコマンドの実行に使用します

#### 手順1

`%userprofile%/Documents/My games/Terraria/tModLoader/ModSources`にModをクローンします。

コマンドラインで`git clone https://github.com/Solaestas/Everglow`を実行してリポジトリをクローンするか、Code --> Download zipボタンからファイルをダウンロードします。

#### 手順2

Everglowをビルドするには、プロジェクトのディレクトリ内でコマンドプロンプトを開きます。
Windowsでは、エクスプローラーでShiftキーを押しながら右クリックし、`Open command window here`を選択すると、すばやく開けます。
次に`dotnet build`コマンドを実行します。ビルドされたファイルは、新しく作成されるbuildディレクトリに出力されます。
